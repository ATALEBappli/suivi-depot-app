# Ressources locales

- `logo.svg` : pictogramme local créé pour le prototype.
- Icônes : SVG intégrés dans `app.mjs`, sans dépendance externe.
- `inter-latin.woff2` : Inter variable latin normal, Fontsource Variable 5.2.8.
- `jakarta-latin.woff2` : Plus Jakarta Sans variable latin normal, Fontsource Variable 5.2.8.
- Sources de distribution : paquets npm officiels `@fontsource-variable/inter` et `@fontsource-variable/plus-jakarta-sans`.
- Licences SIL Open Font License fournies dans les fichiers `*-LICENSE.txt`.

Le navigateur ne télécharge aucune ressource externe.
