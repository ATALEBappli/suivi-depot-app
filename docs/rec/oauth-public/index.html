REC-Synchronisation

REC-Synchronisation est un outil privé de synchronisation et de publication technique utilisé pour l'environnement de recette de Suivi Dépôt.

À quoi sert la connexion Google ?

L'autorisation Google est utilisée par l'administrateur technique pour accéder aux API Apps Script et aux métadonnées Google Drive nécessaires à la maintenance de l'environnement de recette. Elle ne constitue pas un mode de connexion pour les locataires ni pour les utilisateurs métier de Suivi Dépôt.

Accès

Cet outil n'est pas un service ouvert au public : les opérations techniques sont réservées aux personnes explicitement autorisées. Le contenu financier et locatif de l'application de recette n'est pas publié sur ces pages.
